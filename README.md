# Observatorio Trabajo & Salud Mental · 23 ciudades de Colombia

Sitio 100 % estático, todo en la raíz (sin carpetas). No necesita build en Vercel.

- `index.html` — página completa con los datos de las 23 ciudades.
- `tailwind.css` — Tailwind ya compilado.
- `chart.umd.js`, `leaflet.js`, `leaflet.css`, `leaflet-heat.js`, `lucide.min.js` — librerías con versión fija.

Si cambias clases de Tailwind en index.html: `npm install` y `npm run build:css`.
